# Dekha Jaak — Android downloads

APK builds of Dekha Jaak. This repo holds releases only; there is no source code here.

## Install

1. Open the [latest release](https://github.com/sharifrayhan/dekha-jaak-releases/releases/latest) on your Android phone.
2. Download the `.apk` file under **Assets**.
3. Open it. If Android asks, allow your browser to install unknown apps.

## Updating

The app checks for new versions on launch and offers the download. You can also check from **Settings → About → Check for updates**.

Installing a new APK replaces the old version and keeps your library and settings. You don't need to uninstall first.
